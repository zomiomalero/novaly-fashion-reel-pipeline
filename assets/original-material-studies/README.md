# Original procedural material-study library

48 completely original, reproducible 1024x1024 JPEG surface studies (six textile families × eight styling colors). Use for palette prototyping, clothing surface briefing, text contrast studies, and procedural shader testing. **These are NOT photographed fabric, not product images, and NOT evidence of exact real textile color.** Nominal colors are study starting points; lighting and texture alter the sampled pixel values. Source generation: `scripts/build_original_visual_library.py` using NumPy and Pillow with hashed deterministic seeds.
